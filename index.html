使用說明

這是學習紀錄平台的編輯器試用版。工具列的位置和 Word「常用」「插入」索引標籤一樣，在 Word 學到的操作，在這裡大多可以照用。

常用快捷鍵（和 Word 一樣）

粗體／斜體／底線Ctrl + B　Ctrl + I　Ctrl + U
復原／重做Ctrl + Z　Ctrl + Y
複製／剪下／貼上Ctrl + C　Ctrl + X　Ctrl + V
只貼上文字（不帶格式）Ctrl + Shift + V
全選Ctrl + A
放大／縮小字型Ctrl + Shift + >　Ctrl + Shift + <
表格裡跳到下一格／上一格Tab　Shift + Tab
馬上存草稿Ctrl + S

小提醒

  • 圖片：「插入」→「圖片」，或直接把截圖貼上、把圖片拖進來。照片會自動縮小後存到學校的雲端空間。點一下圖片，上方會出現「圖片格式」，可以調大小、靠左／置中／靠右。
  • 影片：「插入」→「影片」，貼上 YouTube 或 Google 雲端硬碟的影片連結。雲端硬碟的影片要設成「知道連結的任何人都能查看」。要刪掉影片，點一下影片再按 Delete。
  • 表格：「插入」→「表格」，用滑鼠選要幾欄幾列。游標在表格裡時，上方會出現「表格版面配置」，可以加列、加欄、刪除。在最後一格按 Tab 會自動多一列。
  • 項目符號、編號：在項目裡按 Tab 變成下一層，Shift + Tab 回上一層。
  • 字型：Chromebook 只有黑體和明體兩種中文字型，沒有標楷體。
  • 送出：寫好了按右上角紅色的「送出」，筆記就會放到你的學習紀錄頁。送出後還可以再改，改完再按一次。
  • 預覽：按右上角的「預覽」，可以看到送出之後，你的學習紀錄頁和這篇文章會長什麼樣子。
  • 自動存草稿：打字停下來約 1 秒就會自動存，狀態列會顯示「草稿已自動儲存」。
  • 存在哪裡：草稿會自動存到學校的資料庫，換一台 Chromebook 登入也看得到。
  • 公開：送出後，到這篇筆記的頁面按「申請公開」。老師通過後，筆記會放到班級展示牆，家長也看得到。

插入影片

貼上 YouTube 影片網址，或 Google 雲端硬碟影片的分享連結。

雲端硬碟的影片，請先在雲端硬碟按「共用」，設成「知道連結的任何人都能查看」，老師和家長才看得到。
