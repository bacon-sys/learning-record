### 三之一、功能
| 項目 | 決定 |
|---|---|
| 編輯頁 | 仿 Word（灰底白紙、工具列照 Word「常用／插入」），按鈕縮小版；內文預設 12 點、顯示比例 120% |
| 送出後的呈現 | 個人部落格：橫幅＋頭像＋筆記卡片；點卡片看整篇 |
| 草稿／送出 | 每篇有「正在寫的版本」和「送出的版本」；部落格、老師、展示牆看的是送出版；送出後可再改，按「再次送出」更新 |
| 搜尋 | 學生搜尋自己寫過的詞（標題＋內文，含草稿），結果標黃，點進去自動捲到那個詞 |
| 帳號編號 | 入學學年＋座號，例：115 學年入學 1 號＝11501（不含年級） |
| 學生密碼 | 系統產生 6 位數；學生可自己改（至少 6 字），改後登入卡密碼失效 |
| 登入卡 | A4 一頁 8 張；QR code 內含帳號＋密碼，Chromebook 相機掃描直接登入 |
| 鎖定 | 連續輸錯 5 次暫停 10 分鐘；老師可解除或重設密碼 |
| 老師帳號 | Email＋密碼；不開放自行註冊；只有管理者（Bacon）能新增老師 |
| 週次 | 每個班級設「第 1 週從哪天開始」；以「第一次送出」的日期算週次 |
| 封存 | 學期結束封存：學生只能看不能改，作品保留，可取消封存 |
| 刪除班級 | 只有開班老師或管理者；要輸入班級名稱確認；連同筆記、照片、名單、展示牆一起刪；可勾選一併刪除「只在這個班」的學生帳號（預設勾選，帳號編號可再用） |
| 分享 | **兩級**：只有自己（含老師）／公開（＝校內＝公開） |
| 公開流程 | 學生在筆記頁「申請公開」→ 老師「通過／不通過」；公開後學生再送出會回到待審核；老師可「取消公開」；學生可撤回 |
| 公開頁名字 | 顯示學生**真名** |
| 家長怎麼看 | 班級展示牆網址（免登入），可複製、印 QR code（A4 一頁 4 張） |
| 公開程度 | 拿到網址才看得到（網址含猜不到的代碼、noindex）；外流時老師可「換一個網址」，舊網址失效 |
| 人臉同意標記 | 不做 |
| 照片 | 自動壓縮到約 230 KB 以內、最長邊 1600px，存雲端空間；卡片封面另存 480×300 縮圖 |
| 影片 | 只收 YouTube 與 Google 雲端硬碟連結；文章頁先顯示封面、按了才載入播放器（YouTube 用 youtube-nocookie）；沒照片時用 YouTube 畫面當封面；不算字數 |
| 外洩密碼保護 | 刻意不開（6 位數密碼幾乎都會被擋） |

# 使用教學（老師版）

**登入**：打開 https://bacon-sys.github.io/learning-record/ → 選「我是老師」→ 輸入 Email 和密碼。

**開學期初**
1. 首頁按「開設班級」，填班級名稱（例：115-1 七年級專題）、學期、第 1 週從哪天開始。
2. 班級的「名單與帳號」：確認「入學學年」，從試算表複製「座號、姓名、顯示名稱」三欄貼上，按「建立帳號並加入班級」。
3. 按「印登入卡」→ 列印（A4 一頁 8 張）→ 剪下發給學生。
4. 升上八年級的學生：在新班級「名單與帳號」右邊「加入已經有帳號的學生」，搜尋後勾選加入。
5. 共同授課老師：「班級設定」輸入對方的 Email 加入。對方還沒有帳號的話，先到右上角「老師帳號」新增。
6. 家長：到「公開審核」分頁，複製「班級展示牆網址」貼到 LINE 群或聯絡簿，或按「印 QR code 給家長」（A4 一頁 4 張）。

**平常**
- 「學生部落格」：一眼看出誰本週已送出、誰還沒寫；可只看「本週還沒送出」。
- 「進度一覽」：每位學生每週一個圓點（綠勾＝已送出、藍雙圈＝草稿、虛線圈＝沒寫），點一列進入那位學生的部落格。
- 「公開審核」：分頁旁的數字＝等你審核的篇數。按「看內容」先讀，再按「通過」或「不通過」。已公開的可以「取消公開」。也可以在學生的筆記頁直接審核。
- 展示牆網址外流時：「公開審核」→「換一個網址」，舊網址和舊 QR code 就打不開，要把新的重新發給家長。
- 學生忘記密碼：「名單與帳號」按「重設密碼」，可單獨印那位學生的登入卡。顯示「暫停登入」的學生，按「解除」。

**學期結束**：「班級設定」→「封存這個班級」。學生只能看、不能改，作品都保留。

**刪除班級**（測試班或開錯的班）：「班級設定」最下面「刪除這個班級」→ 輸入班級名稱確認。筆記、照片會永久刪除；可勾選一起刪掉只在這個班的學生帳號。只有開班的老師或管理者看得到這個按鈕。

**改自己的密碼**：點右上角自己的名字 →「我的帳號」。

# 使用教學（學生版）

1. **登入**：用 Chromebook 的相機掃登入卡上的 QR code，就會直接登入。或打開網址，輸入登入卡上的帳號和密碼，勾「記住我」下次就不用再登入。
2. **寫筆記**：點你的班級 → 按「寫新的筆記」。先打標題，再寫內容。工具列和 Word 一樣（Ctrl+B 粗體、Ctrl+Z 復原⋯）。右上角「使用說明」有完整說明。
3. **放照片**：「插入」→「圖片」，或直接貼上、拖進來。照片會自動縮小、存到學校的雲端空間。
4. **放影片**：「插入」→「影片」，貼上 YouTube 或 Google 雲端硬碟的影片連結。雲端硬碟的影片要先按「共用」，設成「知道連結的任何人都能查看」。
5. **不用按存檔**：停下來一下就會自動存，左下角會顯示「已儲存」。
6. **送出**：寫好按右上角紅色的「送出」，筆記就會放到你的學習紀錄頁。送出前可以先按「預覽」。
7. **想再改**：在學習紀錄頁點那篇 →「修改」，改好再按一次「送出」。
8. **公開給家長看**：送出後打開那篇筆記，按「申請公開」。老師通過後，會放到班級展示牆，上面會顯示你的真名。不想公開了可以按「取消申請」或「不公開了」。公開的筆記再修改送出，要重新等老師審核。
9. **看全班公開的筆記**：學習紀錄頁上的「班級展示牆」。
10. **找以前寫過的東西**：學習紀錄頁的搜尋框，打一個詞就會找出寫過這個詞的筆記。
11. **改密碼**：右上角你的名字 →「我的帳號」。改了以後登入卡就不能用了；忘記就找老師重設。
12. **密碼連錯 5 次**會暫停 10 分鐘，可以請老師幫你解除。
