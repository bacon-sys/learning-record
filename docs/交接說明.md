## 三、已確定的設計決定（含這兩天新增的）
| 項目 | 決定 |
|---|---|
| 編輯頁 | 仿 Word（灰底白紙、工具列照 Word「常用／插入」），按鈕縮小版；內文預設 12 點、顯示比例 120% |
| 送出後的呈現 | 個人部落格：封面（紅黑菱形紋）＋頭像＋卡片；點卡片看整篇 |
| 配色 | 柔和版：主色磚紅 #C0675A、深色 #6E615A、底色 #F8F5F1；文字仍用深色 #2B2725 |
| 草稿／送出 | 每篇筆記有「正在寫的版本」和「送出的版本」；部落格與老師看的是送出版；送出後可再改，按「再次送出」更新 |
| 搜尋 | 學生在自己的學習紀錄頁搜尋寫過的詞（標題＋內文，含草稿），結果標黃，點進去自動捲到那個詞 |
| 帳號編號 | **入學學年＋座號**，例：115 學年入學 1 號＝11501（不含年級，升年級不用改） |
| 學生密碼 | 系統產生 6 位數；學生可自己改（至少 6 字），改後登入卡上的密碼失效 |
| 登入卡 | A4 一頁 8 張；QR code 內含帳號＋密碼，Chromebook 相機掃描直接登入（Bacon 同意這個取捨） |
| 鎖定 | 連續輸錯 5 次暫停 10 分鐘；老師可解除或重設密碼 |
| 老師帳號 | Email＋密碼；不開放自行註冊；只有管理者（Bacon）能新增老師 |
| 週次 | 每個班級設「第 1 週從哪天開始」；以「第一次送出」的日期算週次 |
| 封存 | 學期結束封存班級：學生只能看不能改，作品保留，可取消封存 |
| 外洩密碼保護 | 刻意不開（6 位數密碼幾乎都會被擋） |

# 使用教學（老師版）

**登入**：打開 https://bacon-sys.github.io/learning-record/ → 選「我是老師」→ 輸入 Email 和密碼。

**開學期初要做的事**
1. 首頁按「開設班級」，填班級名稱（例：115-1 七年級專題）、學期、第 1 週從哪天開始。
2. 進到班級的「名單與帳號」：確認「入學學年」（七年級新生是今年，例如 115），從試算表複製「座號、姓名、顯示名稱」三欄貼上，按「建立帳號並加入班級」。
3. 按「印登入卡」→ 列印（A4 一頁 8 張）→ 剪下發給學生。
4. 升上八年級的學生：在新班級的「名單與帳號」右邊「加入已經有帳號的學生」，搜尋帳號或姓名、勾選加入，不用重開帳號。
5. 共同授課老師：「班級設定」輸入對方的 Email 加入。對方還沒有帳號的話，先到右上角「老師帳號」新增（系統給一組暫時密碼，請轉交）。

**平常**
- 「學生部落格」：一眼看出誰本週已送出、誰還沒寫；可只看「本週還沒送出」。
- 「進度一覽」：每位學生每週一個圓點（實心＝已送出、黃圈＝草稿、空心＝沒寫），點一列進入那位學生的部落格。
- 學生忘記密碼：「名單與帳號」按「重設密碼」，會顯示新密碼，可單獨印那位學生的登入卡。顯示「暫停登入」的學生，按「解除」。

**學期結束**：「班級設定」→「封存這個班級」。學生只能看、不能改，作品都保留。

**改自己的密碼**：點右上角自己的名字 →「我的帳號」。

# 使用教學（學生版）

1. **登入**：用 Chromebook 的相機掃登入卡上的 QR code，就會直接登入。或打開網址，輸入登入卡上的帳號和密碼，勾「記住我」下次就不用再登入。
2. **寫筆記**：點你的班級 → 按「寫新的筆記」。先打標題，再寫內容。工具列和 Word 一樣，快捷鍵也一樣（Ctrl+B 粗體、Ctrl+Z 復原⋯）。右上角「使用說明」有完整說明。
3. **不用按存檔**：停下來一下就會自動存，左下角會顯示「已儲存」。
4. **送出**：寫好按右上角紅色的「送出」，筆記就會放到你的學習紀錄頁。送出前可以先按「預覽」看看樣子。
5. **想再改**：在學習紀錄頁點那篇 →「修改」，改好再按一次「送出」。
6. **找以前寫過的東西**：學習紀錄頁上方的搜尋框，打一個詞就會找出寫過這個詞的筆記。
7. **改密碼**：右上角你的名字 →「我的帳號」。改了以後登入卡就不能用了，請記好新密碼；忘記就找老師重設。
8. **密碼連錯 5 次**會暫停 10 分鐘，可以請老師幫你解除。
